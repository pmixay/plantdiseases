# PlantVision — Model Card

> **Per-run provenance lives in `model_card.json` alongside the trained
> artefacts**, not here. Class counts, calibration (`temperature`,
> `conformal`), INT8 drift + paired-bootstrap CI, and per-class recall
> bootstrap CIs are regenerated by `train_notebook.ipynb` §6 on every
> run and shipped with the model files you drop into `server/models/`
> (the server does not auto-download them). This file is a stable,
> version-agnostic overview and carries **no run-specific numbers** by
> design.

## Pipeline

Two stages (`server/pipeline.py`):

1. **Stage 1 — YOLOv8n** single-class `plant_leaf` detector, indoor-trained,
   localises the leaf so Stage 2 sees a tight crop, not a whole room.
2. **Stage 2 — classifier** on the crop at the `classes.json` `img_size`.
   The "is it diseased / which disease" decision is 100 % Stage 2.

Runtime guards: blur gate (variance-of-Laplacian), an OOD AND-gate
(detector confidence **and** a classifier-side OOD signal — embedding
k-NN distance where a bank is shipped, else the legacy MaxLogit floor),
**whole-image-vs-crop arbitration** (the full frame is folded into the
mean vote to recover the detector-crop loss on leaf-centric inputs),
weak-healthy reroute, temperature scaling, and RAPS conformal prediction
sets.

## Classifier architecture

The production artefact is an ONNX graph and the runtime is
**architecture-neutral** — it serves whatever backbone+head the shipped
bundle declares (`classes.json -> architecture`):

- **v2.3.x (current):** frozen **DINOv2 ViT-S/14** backbone + LoRA on the
  later blocks + a small MLP head, **no distillation**. Motivated by a
  frozen DINOv2-S linear probe reaching ~0.91 top-1 on `val_realworld`.
  Shipped FP32 (`PREFER_FP32`) — dynamic-INT8 drift on `val_realworld`
  was not statistically significant (paired bootstrap CI spans 0) and the
  single-core CPU budget has the latency headroom.
- **v2.2 (legacy):** MobileNetV3-Large student distilled from an
  EfficientNetV2-S teacher. Retired in §4/§5 and no longer loadable — the
  runtime is **ONNX-only** (the PyTorch `.pth` fallback was removed).

## Classes

**9 trainable** (alphabetical, = `sorted(ImageFolder.classes)`):
`gray_mold_botrytis`, `healthy`, `leaf_scorch_underwatering`,
`leaf_spot` (merged bacterial + fungal — not reliably separable from a
phone photo), `not_a_plant`, `nutrient_deficiency`, `pests` (merged
mealybugs + scale), `powdery_mildew`, `viral_disease`. The canonical
list is `classes.json` shipped with the trained artefacts.

Content cards exist (no classifier head yet) for deferred conditions
`edema` and `sunburn_or_scorch`.

## Validation contract

| Slice | Role | Pass criterion |
|---|---|---|
| `val_indomain` | training-loop metric, early stopping | best head checkpoint restored |
| `val_realworld` | **primary ship/no-ship gate** | disease macro-F1 ≥ **0.70**; no disease class recall = 0; healthy-bias < 1.5; healthy recall ≥ 0.70 |
| `val_studio` (PlantVillage) | transfer / background-bias monitor | tracked, never blocking |
| `temperature_cal` | temperature scaling | held out |
| `conformal_cal` | RAPS calibration | held out; 80/20 fit/audit when n ≥ 200 |

PlantVillage is **excluded** from the real-world gate and from both
calibration splits — its studio backgrounds violate exchangeability with
the deployment distribution.

## Calibration & OOD

Temperature scaling (Guo et al. 2017) + inductive RAPS conformal
(Angelopoulos et al. 2021) are fit on the **shipped artefact's** logits
so calibration matches what is served. The conformal hyper-parameters
(`alpha`, `lambda_reg`, `k_reg`) are grid-searched on a held-out audit
split for the smallest set size that still clears the 0.90 coverage
target (RAPS otherwise over-covers on this sharp classifier).

**OOD** uses an **embedding-space k-NN distance** (Sun et al. 2022) on
the DINOv2 CLS vector — the classifier ONNX exports the embedding as a
second output, and a memory bank of in-distribution plant embeddings +
a threshold (calibrated at a target plant false-positive rate on a
disjoint split) ship in the bundle (`ood_embedding.npz` +
`classes.json → ood.embedding`). It is AND-gated with detector
confidence. This replaces **MaxLogit** (Hendrycks 2019), which goes dead
once the `not_a_plant` head is confident enough that plant/NAP MaxLogit
separation is non-positive; the MaxLogit floor remains as the fallback
when no embedding bank is shipped (`max_logit_floor`).

## Known limitations

- **Thin classes** (`gray_mold_botrytis`, `leaf_scorch_underwatering`,
  `nutrient_deficiency`) are supply-bound (tens–low-hundreds of
  in-domain images) with small eval slices, so their per-class recall
  CIs are wide — the bundle's `model_card.json` ships those CIs. More
  in-domain data, not a bigger backbone, is the ceiling here.
- `leaf_spot` is a coarse umbrella; no sub-class (fungal vs bacterial)
  accuracy is claimed.
- `viral_disease` is incurable; the pipeline escalates severity by one
  level on a high-confidence viral verdict.
- The dataset mix leans agricultural (PlantDoc / PlantVillage); real
  houseplant recall rides on the iNaturalist supplement and first-party
  data.
